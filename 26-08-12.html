using the 'let' function to declare new variables to control the values of r, g, and b separately.

draw the canvas, and tell the code what each new variable does
(in this case it makes new sliders according to each RGB colour).
this will be how we assign them to control the colours later:

          //draw the canvas in which we will set our retinas on fire with
function setup() {
  createCanvas(windowWidth, windowHeight);
  textAlign(CENTER, CENTER);
  textSize(windowWidth/20);

  //red slider
  sliderRed = createSlider (0, 255, 255, 1);
  sliderRed.position(20, 20);
  sliderRed.size(200);

  // //green slider
  sliderGreen = createSlider (0, 255, 255, 1);
  sliderGreen.position(20, 50);
  sliderGreen.size(200);

  // //blue slider
  sliderBlue = createSlider (0, 255, 255, 1);
  sliderBlue.position(20, 80);
  sliderBlue.size(200);
}

declare new variables which is the value from the sliders (defined by slider[Colour].value()), this will be how new colours are generated: 

          function draw() {
  let re = sliderRed.value();
  let gr = sliderGreen.value();
  let bl = sliderBlue.value();

create labels for the sliders so it tells us the RGB values the colours are generated within. push and pop probably aren't necessary but it gives me peace of mind:

if mouseIsPressed tells the code to generate a new colour between the values defined by variables earlier in the code with re, gr, and bl.
the function randomColourValue is used to constrain the numbers to be between 0 and 255, so that actual colours are generated when you click your mouse.
this is also where random() is used to randomise the colours.
the (value) in this function is replaced by re, bl, and gr, which returns the value of the sliders, which generates our colours. 

            //where the magic happens
  if (mouseIsPressed) {
    bgColor = color(
      randomColourValue(re),
      randomColourValue(gr),
      randomColourValue(bl),
    );
  }
        
        function randomColourValue(value){
  return constrain(random(value -15 , value +15), 0, 255);
}
